# flutter_pageable example

A locally backed Flutter showcase for the package's main pagination features.

```sh
flutter pub get
flutter run -d chrome
flutter test
```

The four tabs demonstrate a cached, filterable and bidirectional feed; all
five pageable layouts; multi-source interleaving with round-robin, priority
and custom strategies; runtime source management and isolated failures; typed
cursor pagination; retry, polling and refresh controls; and bundled helpers.
No network access or additional runtime packages are required.
